# MTB Telemetry

DIY MTB Telemetry Logger

Hardware

- Raspberry Pi 4
- ADS1256
- MPU6050
- Haltech HT-011202
- Hall Sensor
- GPS NEO-6M

Sampling Rate

- Suspension: 500 Hz
- IMU: 500 Hz
- GPS: 5 Hz
- Hall Sensor: Interrupt
